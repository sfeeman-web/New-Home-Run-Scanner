Outlaw Scanner Replacement

Files included:
- scanner.py
- app.py

Installation:
1. Unzip this package.
2. Upload scanner.py over the existing scanner.py in GitHub.
3. Upload app.py over the existing app.py in GitHub.
4. Commit changes.
5. Streamlit should redeploy automatically.

Configured behavior:
- 10-game recent-form window
- Historical batter-vs-pitcher matchup data
- Active-roster validation
- Confirmed lineup not required
- Opposing pitcher required
